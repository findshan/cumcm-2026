## B 题 · 无线电干扰源的快速自动定位与清除

机器狗携带测向机，在半径 1800 m 圆域内自主搜索、定位并清除 10–16 个位置/个数/频道均未知的干扰源，最小化总虚拟时间（移动 + 检测 + 换频 + 清除）。

**核心洞察（决定方案上限的六点，详见 [docs/B题_题目理解与建模方案.md](B-problem-jammer-localization/docs/B题_题目理解与建模方案.md)）**

1. 示向度误差是**位置相关的确定性偏差场**（|e|≤1°），不是白噪声 → 这是**集值估计**问题，可行集（楔形交）的直径就是天然不确定度度量；Q1 的"区域直径"正是为 Q2 提供损失函数。
2. 单次 `direction` 返回"2° 楔形 ∧ 半径 1500 m 截断" → 交会定位从无界问题变有界问题。
3. 20 个频道是 20 个可解耦的独立估计问题，**路径是唯一耦合项** → 上层路径调度 + 下层逐频道滤波的分解骨架。
4. `/clear`（20 m、3–5 s）是廉价的近距二值传感器 → 存在定量"转清剿"阈值（可行集直径 ≤ 40 m）。
5. Q2 的真张力是**交会条件数 vs 接收保证**：纯垂直基线必丢远端源 → 交会角约束锁定了 Q3 的锯齿形巡视几何。
6. Q4 定向源把 `no_signal` 变成半平面（阴影）约束 → 保证检测要求源落在测点集凸包内部，边界穿越点同时给出位置与定向方向的线性约束。

**模拟器评估**（`code_sim/`，50 次蒙特卡洛/档）：

| 定向源比例 | 本方案清除率 | 基线清除率 |
|---|---|---|
| 0%（全向，Q3） | **100%**（50/50 全清） | 100% |
| 20% | **96.5%** | 91.0% |
| 50% | **93.1%** | 76.2% |
| 100%（全定向，Q4） | **90.9%** | 55.0% |

全向场景平均定位清除时间约 **3754 s**（50 次全清）；定向源比例越高，相对基线的优势越大（Q4 档 +35.9 个百分点清除率）。

## C 题 · 社区微电网购电策略

以"决策时刻可获得的信息集"为纽带，四个小问统一为同一数学模型在信息逐层收缩下的递进体系：LP（信息完备）→ 朴素滚动 → **罚金感知滚动时域优化 MPC-II**（光伏不确定）→ 双轨决策（电价不可预知），并以**随机动态规划（SDP）**给出最优性基准。

**关键结果**

| 指标 | 数值 |
|---|---|
| 无储能基线全年费用 | 1 640.7 万元 |
| 储能套利价值 | −416.2 万（−25.4%） |
| MPC-II 交付方案全年费用 | **1 424.9 万元**（口径 A：14 248 837.72 元） |
| SDP 最优基准（同信息结构） | 13 869 883.17 元，MPC-II 与之**仅差 0.16%**（同口径实测差距） |
| 滚动优化固有次优性 | 0.37%（预报完全准确时） |
| 光伏预报误差贡献 | +195.8 万（+11.9%）；误差减半省 6.9%，翻倍多花 13.6% |
| 尾部风险 | CVaR₉₅ 仅超期望 0.42% |

SDP 的定位是**最优性基准而非最优性证明**：Bellman 最优性原理严格成立于离散化问题内；动作网格（250 kW）收缩可行域、状态网格与经验分位点引入近似，离散化误差方向明确（SDP 费用只会被高估）但未给严格界。
