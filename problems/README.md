# 官方题目与附件（CUMCM 2026）

本目录收录 2026 年高教社杯全国大学生数学建模竞赛 B、C 两题的官方题目与附件数据，供**学习与研究**使用。

> **版权声明**：下列题目、附件数据与结果模板的著作权归全国大学生数学建模竞赛组织委员会所有，来源为竞赛官网 <https://www.mcm.edu.cn>（赛题包 `CUMCM2026Problems.zip`）。此处仅为复现本仓库解法所需的存档，不作任何商业用途。如需正式引用或再分发，请以官网原文为准。

## B 题 · 无线电干扰源的快速自动定位与清除

| 文件 | 说明 |
|---|---|
| `B题.pdf` | 题目正文（4 页），含附录 1 干扰源特征、附录 2 检测原理 |
| `B题_附件/附件1.docx` | **模拟器使用说明**（行为规则、虚拟计时、网盘下载、登录注册） |
| `B题_附件/附件2.docx` | **模拟器通信接口说明及编程指南**（`/enter` `/measure` `/clear` `/exit`、JSON 字段、HTTP 状态码、幂等与重试） |

> 注意：两个附件的**文件名不含内容信息**——附件1 不是"干扰源特征"，干扰源特征在题面附录1 里。这是本仓库 B 题解法的原始目录，供核对建模依据。附件中还包含官方模拟器的网盘下载地址。

## C 题 · 社区微电网购电策略

| 文件 | 说明 |
|---|---|
| `C题.pdf` | 题目正文（4 页），含附录物理参数（储能容量、充放电功率、效率、初始电量等） |
| `C题_附件/附件1.xlsx` | 典型日：电价 / 小区负载 / 光伏发电预测功率（10 分钟粒度，144 时段） |

| `C题_附件/附件4.xlsx` | 全年电价（10 分钟粒度） |
| `C题_附件/附件5/result*.xlsx` | 官方结果填报模板（**空模板**） |

## 复现时如何摆放

`C-problem-microgrid/code/cumcm_core.py` 按固定相对路径读取附件
（`DATA_DIR = code/../data/附件`）。clone 之后执行一次：

```bash
cd C-problem-microgrid
mkdir -p data && cp -r ../problems/C题_附件 data/附件
```

B 题的模拟器为自研实现，**不依赖**官方附件，可直接运行；两个 docx 仅用于核对接口语义。
