# 第一部分 · 一分钟把题讲透

这道题本质上只有一个问题，被拆成四层：

> **一个装有光伏和电池的微网，每天 0 点要决定"从电网买多少电、电池怎么充放"，使得小区不断电，且买电总费用最小。**

四个小问的差别，**不是模型结构变了，而是"做决策时你掌握了多少信息"变了**：

| | 光伏出力 | 外网电价 | 决策节奏 | 不确定性的来源 |
|---|---|---|---|---|
| **问题1** | 已知（预测） | 已知且每天相同 | 0:00 定一次 | **无**（完全确定） |
| **问题2** | 已知（实际） | 已知且每天相同 | 每天 0:00 | **无**（完全确定） |
| **问题3** | **只有预报**，实际未知 | 已知且每天相同 | 0:00 定计划，6/12/18 点调整 | **光伏预报误差** |
| **问题4** | 只有预报 | **实时波动、不可预知** | 同问题3 | **预报误差 + 电价波动** |

**这就是整道题的骨架：信息集逐层收缩，模型从"确定性线性规划"→"两阶段随机优化"→"在线/鲁棒决策"。**

把这个视角立住，四个问题就是一个框架的四个特例，论文的骨架会非常干净——这是拉开档次的第一刀。

# 第二部分 · 系统与符号

## 2.1 系统构成

```
                         ┌──────────── 外部电网 (Grid) ────────────┐
                         │   购电 g_t (元/kWh 电价 c_t)            │
                         │   紧急购电 e_t (5c_t) / 违约调整        │
                         └────────────────┬────────────────────────┘
                                          │
   ┌──────────┐   光伏 S_t        ┌───────▼────────┐        ┌──────────┐
   │ 光伏阵列 │──────────────────►│   微网母线     │───────►│ 小区负载 │
   └──────────┘                   │  功率平衡      │        │   L_t    │
                                  └───────┬────────┘        └──────────┘
                                          │ 充 u_t / 放 v_t
                                  ┌───────▼────────┐
                                  │  电池储能 ESS  │   E_t ∈ [1200, 10800] kWh
                                  └────────────────┘
```

**关键**：本题**不允许向电网售电**（全文只出现"购电量"，没有"售电/上网"）。
→ 所以当"光伏 > 负载 + 充电能力"时，多余电量只能 **弃光**。这是必须显式建模的变量，
**漏掉这一条的队伍会算出"凭空卖电省钱"的假结果。**

## 2.3 核心约束与目标

**功率平衡（每个时段 t）**

$$S_t + g_t + a_t + e_t + v_t = L_t + u_t + w_t$$

**"供电不低于负载"** 与上式等价于 $w_t \ge 0$，即弃光非负——这是个漂亮的等价写法，
比写成不等式更利于求解器处理。

**储能动态（含效率）**

$$E_{t+1} = E_t + \eta\, u_t \,\Delta t - \frac{v_t \,\Delta t}{\eta}$$

**目标**

$$\min\; \Phi = \underbrace{\sum_t c_t\,g_t\,\Delta t}_{\text{计划购电费}} + \underbrace{\Phi_{\text{adj}}}_{\text{调整费}} + \underbrace{\sum_t 5c_t\,e_t\,\Delta t}_{\text{紧急购电费}}$$

| 1 | +1.21 | 18.7 | 41.0 | 0.18% |
| 2 | +0.51 | 35.0 | 68.1 | 0.34% |

| 6 | −4.98 | 90.0 | 209.5 | 0.88% |
| 9 | −13.10 | 156.8 | 277.7 | 1.53% |

**两个关键特征（问题3 建模的全部依据）：**

1. **误差离散度随提前期单调放大 ~20 倍**（白天样本：MAE 37.4 → 750.1 kW，σ 57.9 → 1257.3 kW）。
   → 预报的"时效性衰减"可标定，用 $\sigma(k)$ 关于 $k$ 的幂函数刻画（实测 $\sigma(k)\approx 58k$，$R^2$ 高）；
2. **均值偏差很小、且方向为「预报偏低」**：以 $\varepsilon_k = \hat{S}_k - S$ 记（预报 − 实际），
   实测 $\bar\varepsilon_1 = +2.4$ kW → $\bar\varepsilon_{24} = -208.6$ kW，白天样本总体均值仅 $-47$ kW；
   全年电量口径预报 20 015 MWh vs 实际 20 251 MWh，**低估 1.2%**。
   即预报略偏保守，量级远小于其离散度（$|\bar\varepsilon_{24}|/\sigma_{24}\approx 0.17$）。
   → 关键判断：**问题3 的紧急购电由误差的「离散度」而非「均值偏差」驱动**。
   因此建模重点是刻画 $\sigma(k)$ 与误差分布的形态（实测**左偏**：长尾为"实际远高于预报"），
   而不是只做一个常数偏差修正。

**问题3 的不确定性模型可以直接用这张表：**

$$\varepsilon_k = \hat S_{\text{预报}} - S_{\text{实际}} \sim \mathcal N(\mu_k,\ \sigma_k^2),\qquad \mu_k,\sigma_k \text{ 由附件3/附件2 标定}$$

## 3.6 ★发现三：储能套利在本题数据下"永远有利可图"

设充电电价 $c_{\text{low}}$，放电时段电价 $c_{\text{high}}$，往返效率 $\eta^2$。
**储能套利值得做** 的条件是：

$$\frac{c_{\text{high}}}{c_{\text{low}}} > \frac{1}{\eta^2} = \frac{1}{0.81} = 1.235$$

实测：

- 附件1（平均日）：峰谷比 **2.92** ≫ 1.235 ✔
- 附件4（全年）：**365/365 天**的日内峰谷比中位数 **4.33** ≫ 1.235 ✔

→ **每一天都存在套利空间**，储能的充放电时序由电价主导。这也说明：
**问题2/3/4 的费用对该阈值高度敏感**，把 $\eta$ 当灵敏度参数扫一遍，是很自然且必要的分析。

# 第四部分 · 四问逐层拆解

## 问题1 · 单日确定性线性规划（LP）

**设定重述**：电价、负载每天相同，给出光伏一天的预测数据；供电不得低于负载；
储能 0:00 与 24:00 储电量相同。

**模型**

$$\min_{g,u,v,w,E}\ \sum_{t=1}^{144} c_t\,g_t\,\Delta t$$

$$\text{s.t.}\quad S_t + g_t + v_t = L_t + u_t + w_t \quad \forall t$$

$$E_{t+1} = E_t + \eta u_t \Delta t - \tfrac{1}{\eta} v_t \Delta t,\quad E_0 = E_{144} = 6000$$

$$1200 \le E_t \le 10800,\qquad 0 \le u_t, v_t \le 5000,\qquad g_t, w_t \ge 0$$

**性质**：纯 LP，**144 组变量、单日瞬时可解**。

**理论上可以做的加分项（对偶分析）**
LP 的对偶变量就是约束的影子价格：
- 功率平衡约束的乘子 λ_t = **该时段的边际电价**；
- 储能动态约束的乘子 = **储能的边际价值（影子储电价值）**；
- 由此可得最优策略的结构：**当且仅当该时段的边际电价低于"储能的边际价值"时才充电，反之放电**，
  并且给出 §3.6 的套利阈值 $c_{\text{high}}/c_{\text{low}} > 1/\eta^2$。

> 把这段写进论文，瞬间从"套模型"变成"讲机制"——这正是评奖标准里的「**建模的创造性**」。

**交付**：`result1.xlsx`
- 工作表「计划购电量」：144 行，10 分钟粒度（行标签形如 `0:10-0:20`）
- 工作表「充放电量」：6 个 4 小时时段 + 0:00 / 24:00 储电量
- 论文表 1（指定时段购电量 + 全天购电量/购电费）、表 2（指定时段充放电量 + 首末储电量）

**易错点**
- 附件1 的时间标签是**区间右端点**（首行 `00:10` 代表 0:00–0:10 时段，末行 `0:00+1` 代表 23:50–24:00）；
- 而 result1 模板的时段标签写作 `0:10-0:20`……**两者存在一处错位，必须逐行比对模板确认**（见 §6-6）；
- 储能首末电量相等是**硬约束**，漏掉会导致"一天内放空电池"的退化解。

## 问题2 · 全年逐日确定性 LP（365 天滚动）

**设定重述**：电价每天相同（取附件1 的电价），负载和光伏随时间变化（取附件2 实际值）；
供电不得低于负载，不足则紧急购电（**5 倍电价**）；每天 0:00 制定当天计划。

**模型**：与问题1 同构，但**去掉首末电量相等约束，改为跨日连续**：

$$E_{t+1}=E_t+\eta u_t\Delta t-\tfrac1\eta v_t\Delta t \quad \text{跨日衔接},\qquad E_{2025.1.1\,00:00}=6000$$

逐日求解 365 个 LP（或整年一次求解 365×144 规模的 LP）。

### 🔴 本题最重要的一处理解：问题2 的"紧急购电"恒为 0

题目对紧急购电的描述是"**如果低于负载，需向外网紧急购电**"，
而问题2 明确"根据**附件1中的电价**和**附件2中的数据**"制定计划——
**附件2 是实际值，即问题2 是完美信息下的确定性优化。**

只要硬约束 $w_t \ge 0$（供电 ≥ 负载）成立，**紧急购电永远不会被触发**。

所以：
- 紧急购电这一机制**本质是为问题3 预埋的**（问题3 中计划基于预报、实际是附件2，偏差必然发生）；
- 问题2 的 `紧急购电量` 工作表**应填 0 / 空**，
- **但必须在论文中把这一点讲清楚**：说明"确定性设定下紧急购电为 0，该机制在问题3 中才被激活"。

> ⚠️ 反面教材：如果论文里问题2 算出了大量紧急购电，说明模型把"供电 ≥ 负载"当成了软约束，
> 属于**建模错误**，会被直接扣分。反过来，主动指出这一点的队伍会显得对题目理解更透彻。

### 🔴 第二处关键：为什么结果从 **2 月 1 日** 才开始？

`result2/3/4-*.xlsx` 的「计划购电量」工作表都是 **A1:EQ335 → 334 天 = 2025.2.1 – 12.31**，
而附件2、附件3、附件4 都从 **1 月 1 日** 开始。

**结论：1 月是"预热期 / 初始化期"。**

理由：储能初值只给定在 **2025.1.1 0:00 = 6000 kWh**，而逐日滚动求解下，
1 月的储电量轨迹还带着初值的"瞬态"，到 2 月初才进入稳态。因此：

- **实现上**：从 1/1 起全程滚动求解，**只输出 2/1 起的结果**；
- **论文里**：明确写出这一处理，并可以画出 1–2 月的储电量轨迹来**证明** 2 月初已进入稳态
  （这是一张很漂亮、很有说服力的图，能证明"我们想清楚了"）。

## 问题3 · 两阶段随机优化（本题的得分主战场）

**设定重述**：
- 每天 **0:00 / 6:00 / 12:00 / 18:00** 可获得**未来 24 小时整点**的光伏功率预报（附件3）；
- 0:00 的预报 → 制定当天**计划**购电策略；其他时刻的预报 → 制定**调整**购电策略；
- 计划 > 调整 的部分：**违约电价 = 交易时刻电价的 50%**；
- 调整 > 计划 的部分：**超出部分电价 = 交易时刻电价的 1.5 倍**；
- 总费用 = 计划购电费用 + 紧急购电费用 + 调整购电量的相关费用。

### 决策结构

```
0:00  ──[拿到0:00的24h预报]──► 制定全天144点的计划购电 plan_t
  │
6:00  ──[拿到6:00的24h预报]──► 调整当天剩余时段的购电量 adj_t
  │
12:00 ──[拿到12:00的24h预报]─► 再调整
  │
18:00 ──[拿到18:00的24h预报]─► 再调整
  │
全天按附件2的实际负载/光伏执行 ──► 若不足则5倍紧急购电
```

**三个技术难点，逐一定点突破：**

**难点1：预报是"整点"（24 点），决策是"10 分钟"（144 点）→ 必须降尺度**
- 可用的物理约束：光伏日出 06:00、日落 18:00、正午峰值，曲线近似钟形；
- 建议方法：**以预报整点值为控制点的分段三次样条 / 保形插值（PCHIP）**，
  并在日出日落区间外强制为 0（避免插值出负值或夜间的虚假出力）；
- ⚠️ 用线性插值会在日出/日落陡坡处产生明显偏差，评委会看出粗糙。

**难点2：误差随提前期增长 → 必须标定不确定性的"时间衰减"**
- 直接用 §3.3 实测的 $\mu_k, \sigma_k$ 拟合关于 k 的函数（如 $\sigma_k = \alpha k^{\beta}$）；
- 注意均值偏差**量级小但随 k 变号**（由轻微正偏转为 −208 kW），主导项是 $\sigma_k$；
- 误差分布**左偏且异方差**（离散度近似正比于出力水平），宜用**经验条件分位**而非单一正态；
- 这一步做好了，就是全篇最有说服力的实证支撑。

**难点3：费用口径存在歧义 → 必须显式声明（见 §6-5）**

### 推荐建模路线（按性价比排序）

**路线 A：滚动确定性优化 / MPC（必做，保底）**
每个预报时刻，用"当前预报 + 已知实际"求解一个确定性 LP，得到该时刻之后的购电量。
实现简单、结果稳健、一定能出结果。

**路线 B：两阶段随机规划 / 场景法（冲国一必做）**
- 阶段1（0:00）：决策 plan，此时只知道预报；
- 阶段2（6/12/18:00）：决策 adj，此时预报更新；
- 用 §3.3 的误差分布生成 $N$ 个光伏场景（建议 100–500 个，或用拉丁超立方抽样）；
- 目标：$\min\ \mathbb E_\omega[\Phi]$，用 SAA（样本平均近似）求解；
- 输出：期望费用、费用分布、CVaR（风险度量）。

**路线 C：鲁棒优化（可选，加分项）**
对最坏场景下的费用最小化——适合论证策略的稳健性。

### "是否需要引入其他时刻的预报？"

这是题目明确要求回答的问题，**标准做法是算"信息的边际价值"**：

| 可用预报 | 期望总费用 | 相对仅用 0:00 预报的节省 |
|---|---|---|
| 仅 0:00 | Φ₁ | — |
| 0:00 + 12:00 | Φ₂ | Φ₁−Φ₂ |
| 0:00 + 6:00 + 12:00 + 18:00 | Φ₃ | Φ₁−Φ₃ |
| 完美信息（用附件2 实际值） | Φ* | Φ₁−Φ* = **EVPI** |

用 **EVPI（完美信息价值）** 和 **VSS（随机解价值）** 这两个随机规划的标准指标来回答，
比"我觉得需要"高出一个档次。**这是本题最容易做出彩的地方。**

## 问题4 · 波动电价下的在线决策

**设定重述**：外网电价实时波动（附件4）。用附件2 的负载与光伏实际、附件3 的光伏预报、
附件4 的电价数据，**在波动电价下重新计算问题2 和问题3**。

### 核心矛盾

"每天 0:00 制定计划" + "电价实时波动、且 0:00 时并不知道全天电价"
→ **信息结构比问题3 更差**（问题3 至少电价是已知的）。

### 推荐"双轨"处理（这是问题4 的最优解，也是最容易被忽略的）

**轨道一：完美信息基准（下界）**
直接拿附件4 的实际电价做确定性优化 → 得到费用下界 $\Phi_{\text{PI}}$，
代表"如果能预知电价"的理论最优。

**轨道二：可实现策略**
0:00 时不知道未来电价，只能：
1. **电价预测**：用附件4 的历史电价（或前若干日的电价）建立预测模型
   （分时段均值 + 分位数、ARIMA、或简单的时间序列基线都行，重点是**给出预测不确定性**）；
2. **滚动优化**：随实际电价信息逐步披露，不断修正购电与充放电计划；
3. 或用**阈值策略 / 随机动态规划**直接给出"电价高于多少就放电、低于多少就充电"的规则。

**两者的差 $\Phi_{\text{MI}} - \Phi_{\text{PI}}$ 就是"电价不确定性的成本"**，
这是问题4 最有价值的定量结论。

**问题4 的本质升华（写进论文会很出彩）**
问题1–3 中，储能的价值是"**确定性套利**"（低买高卖）；
问题4 中，电价不再可预知，储能的价值变成"**不确定性下的期权价值**"——
它让你**有权但无义务**在高价时放电、在低价时充电。
用这个视角写模型评价与推广，档次立刻不同。

- `result4-3.xlsx`：波动电价下重做问题3（+ 调整购电量）

# 第五部分 · 统一求解框架与论文骨架

## 5.1 建议的统一表述

定义通用问题 $\mathcal P(\mathcal I)$，其中 $\mathcal I$ 是**决策时刻可获得的信息集**：

$$\min_{\{g,u,v,w,E\}}\ \mathbb E\!\left[\sum_{t}\Big(c_t\,g_t + \gamma_t^{\text{adj}}\Delta g_t + 5c_t\,e_t\Big)\Delta t \ \Big|\ \mathcal I\right]$$

$$\text{s.t.}\quad S_t + g_t + \Delta g_t + e_t + v_t = L_t + u_t + w_t$$
$$\qquad\ E_{t+1}=E_t+\eta u_t\Delta t-\tfrac{1}{\eta}v_t\Delta t$$
$$\qquad\ E_t\in[1200,10800],\ u_t,v_t\in[0,5000],\ g_t,\Delta g_t,e_t,w_t\ge0$$

**四个问题 = 四档信息集：**

$$\mathcal I_1 \supset \mathcal I_2 \supset \mathcal I_3 \supset \mathcal I_4$$

| 问题 | 信息集 | 模型类型 |
|---|---|---|
| 1 | 单日全知 | 确定性 LP |
| 2 | 全年逐日全知 | 确定性 LP（365 次） |
| 3 | 光伏仅预报 | 两阶段随机 LP / MPC |
| 4 | 光伏+电价均不确定 | 在线决策 / 鲁棒优化 |

费用关系必然是 $\Phi_1 \ge \Phi_2$ 型的信息价值单调性（可实测验证）。

### 关于 #5（费用口径）的详细说明

题目原文："计划购电量高于调整购电量的部分，违约电价是交易时刻电价的 50%；
调整购电量高于计划购电量的部分，超出部分的电价是交易时刻电价的 1.5 倍。"

**口径 A（推荐，字面最贴合"三项并列"）**

$$\Phi_{\text{adj}} = \sum_t\Big[\,0.5\,c_t\,(g_t-a_t)^+ + 1.5\,c_t\,(a_t-g_t)^+\,\Big]\Delta t$$

其中计划购电费另按 $\sum c_t g_t\Delta t$ 全额计。含义是"照付不议 + 偏差罚款"。
**推论**：向下调整永远不划算 → 调整的唯一动机是**避免 5 倍紧急购电**。

**口径 B（备选，避免重复计费）**

$$\Phi = \sum_t\Big[c_t\min(g_t,a_t) + 0.5c_t(g_t-a_t)^+ + 1.5c_t(a_t-g_t)^+\Big]\Delta t$$

含义是"分段结算：共同量按 c、欠量按 0.5c、超量按 1.5c"。此时向下调整反而省钱，策略空间更丰富。

**处理建议**：以 A 为主模型，在灵敏度分析里给出 B 的结果，说明**结论对该口径的稳健性**。
论文中**必须显式写出费用公式并解释**，绝不能含糊带过。
