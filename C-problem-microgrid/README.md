# C 题 · 社区微电网购电策略：信息集递进与滚动时域优化

## 一、统一模型

四个小问共用一个目标函数与约束组，差别只在**信息集**与**储能边界条件**：

$$\min\ \Phi=\underbrace{\sum_t c_t\,g_t\,\Delta t}_{\text{计划购电费}}+\underbrace{\sum_t\big[0.5c_t(g_t-a_t)^+ +1.5c_t(a_t-g_t)^+\big]\Delta t}_{\text{调整相关费用}}+\underbrace{\sum_t 5c_t\,e_t\,\Delta t}_{\text{紧急购电费}}$$

| | 电价 | 光伏 | 决策结构 | 储能边界 |
|---|---|---|---|---|
| 问题1 | 固定日曲线 | 预测（全知） | 单日一次决策 | 日周期 E(0:00)=E(24:00)=6000 |
| 问题2 | 固定日曲线 | 实际（全知） | 整年一次求解 | 跨日连续，年末 ≥6000 |
| 问题3 | 固定日曲线 | **仅预报** | 0:00 定计划 + 6/12/18 点调整 | 日周期 =6000 |
| 问题4 | **实时波动** | 仅预报 | 同问题3 | 同问题3 |

**关键建模判定**

1. **不允许向电网售电**——题面只出现"购电量"，余电只能充电或弃光（引入弃光变量 w≥0）。
2. **问题2 的紧急购电恒为 0**——附件2 是实际值，问题2 即完美信息优化；该机制实为问题3 预埋。
3. **附件1 = 全年平均日**——实测其电价/负载/光伏与逐时段均值在 1e-4 内吻合。
4. **交付期从 2/1 起**——模板只要求 2025.2.1–12.31（334 天），1 月为预热期。

## 二、方法递进

1. **问题1/2：确定性 LP**（scipy/HiGHS）。问题1 全天购电 59 482.7 kWh、费用 35 126.9 元，储能日周期闭合、无同时充放电、无售电。
2. **问题3 → MPC-II（罚金感知滚动时域优化）**：光伏不确定下，把"调整购电量的不对称费用"（上偏 0.5c、下偏 1.5c）与"紧急购电 5c 罚金"写进滚动目标，而非只优化计划购电。修正后全年费用 1 424.9 万（调整费用从 66.3 万降至 43.3 万，省 356 733 元 / −2.50%）。
3. **信息价值分解**：6/12/18 点三次追加预报可挽回 3.44%；误差减半省 6.9%、翻倍多花 13.6%——**预报精度比决策方法收益更大**。
4. **问题4：双轨决策**，对电价不可预知部分做鲁棒/情景处理，电价系统性水平（而非波动性）是费用的一阶驱动。
5. **SDP 最优性基准**：状态恰为储电量一维 → 97×41 网格随机动态规划（全年仿真 30 s），解得基准费用 13 869 883.17 元，MPC-II 与之仅差 **0.16%**（同信息结构、同结算口径实测差距；定位为基准而非证明——离散化偏差方向明确但无严格误差界）。

## 四、复现

官方附件在仓库根目录 `problems/C题_附件/`。代码按固定相对路径读取附件
（`cumcm_core.py: DATA_DIR = code/../data/附件`），clone 后先摆一次：

```bash
cd C-problem-microgrid
mkdir -p data && cp -r ../problems/C题_附件 data/附件
```

然后按顺序运行：

```bash
cd code
python3 04_p1.py && python3 05_p2.py && python3 06_p3.py && python3 07_p4.py   # 四问
python3 18_sdp.py                        # SDP 基准（~30 s）
python3 19_mpc_penalty.py                # MPC-II 罚金感知滚动
python3 22_paper_tables.py               # 重新生成论文全部表格
```

依赖：python3 + numpy + pandas + scipy（内置 HiGHS 求解器）。全流程 < 2 分钟。
附件5 为官方结果填报模板（空模板），随题目一起收录在 `problems/`。
